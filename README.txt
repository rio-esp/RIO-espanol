RIO Español v9 — GitHub Pages / PWA版

【公開方法】
1. GitHubにログインして新規のPublicリポジトリを作成します（例: rio-espanol）。
2. このZIPを解凍し、フォルダ内のファイルをすべてリポジトリのルートにアップロードします。ZIPファイルだけをアップロードしても公開できません。
3. リポジトリの Settings → Pages → Build and deployment で Deploy from a branch を選び、Branch: main / (root) を指定して Save。
4. 公開された https://ユーザー名.github.io/rio-espanol/ をAndroidのChromeで開きます。
5. Chromeメニュー →「アプリをインストール」または「ホーム画面に追加」を選びます。

【更新方法】
今後は更新されたファイルを同じリポジトリに上書きアップロードします。インストールし直す必要は通常ありません。更新の反映には少し時間がかかる場合があります。

【学習履歴】
ローカルHTML版とWeb版は保存領域が異なります。v8の「設定」でJSONバックアップを作成し、Web版で復元してください。旧版を削除する前に記録を確認してください。

【注意】
GitHub Pagesは公開Webサイトです。個人情報やAPIキーをファイルに入れないでください。
初回はオンライン接続が必要です。以降はキャッシュされた範囲でオフライン利用できます。
Android実機でのインストール・履歴復元は利用者側で確認してください。
